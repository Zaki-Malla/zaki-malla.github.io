Wassiili Mobile Application

StartedApr 2026Duration2.5 monthsCompleted
Customer Mobile App

Business Purpose

The application was designed to simplify the customer ordering experience, reduce manual communication, organize pricing requests, and connect the mobile customer journey directly with internal pricing, finance, approval, and operational teams.

Technical Stack

Flutter Dart Riverpod WebView HTTP APIs Flutter Secure Storage ASP.NET Core API JWT Authentication EF Core SQL Server
Customer AuthenticationLogin, registration, validation, and secure API access.
SHEIN In-App ShoppingWebView-based browsing and product selection inside the application.
Product ExtractionReads product name, image, price, link, size, and color when available.
Internal CartProducts are added into an app cart with quantity selection before pricing.
Pricing RequestsCarts are sent to employees for pricing inside the main Wassiili system.
Approval FlowCustomers can approve or reject priced products or carts.
SYP WalletWallet balance, payment history, and mandatory receipt image for submissions.
NotificationsIn-app and Android notification support for customer updates.

Security and API Controls

  • Secure token storage on the device.
  • JWT-based mobile authentication with independent API flow.
  • X-App-Build header to identify application build versions.
  • Ability to block outdated application versions from API usage.
  • Rate limiting on /api/v1 routes to reduce abuse and pressure.
  • Payment submissions rejected when receipt image is missing.
  • User validation before showing wallet, requests, or notifications.
  • Production usage based on HTTPS and standard protection policies.

Operational Note

The mobile app communicates with the existing backend through authenticated APIs, keeping customer actions connected to employee operations.

Wassiili System

An ASP.NET Core MVC and SQL Server platform for a shopping intermediary business, connecting pricing, purchasing, payments, shipments, and employee workflows.

StartedJun 2025DurationSince Jun 2025Active now
Operations Platform
Explore project details +

Business Context

The system supports the operational workflow of receiving customer orders from platforms such as SHEIN and Trendyol, pricing them, purchasing them, tracking arrival, grouping products into shipping bags, sorting them, calculating payments, and managing delivery to customers.

Order LifecycleProducts move from customer request to pricing, approval, purchase, arrival, sorting, and delivery.
Carts & ProductsProduct records are connected to pricing requests, carts, and customer ownership.
Bags / ShipmentsProducts are grouped into bags and tracked across shipping and sorting stages.
Wallet & PaymentsCustomer balances, SYP payments, receipts, remaining balances, and histories.
Multi-Currency LogicConceptual handling for SAR, USD, and SYP with exchange rate storage.
Financial ReconciliationFees, discounts, coupons, points, wallet effects, and operational reporting.
Employee DashboardsTables, filters, forms, modals, and internal pages for operational teams.
Security ModelASP.NET Identity, roles, permissions, validation, and secure access control.

Technical Implementation

  • C# and ASP.NET Core MVC with dependency injection.
  • Entity Framework Core, SQL Server, and the repository pattern.
  • ViewModels for page data and ASP.NET Identity for access control.
  • Search, filtering, Excel import/export, and notifications.

Structured MVC Architecture

Repositories isolate data access; controllers coordinate validation and business logic; ViewModels prepare data for admin and employee screens.
