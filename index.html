Wassiili Mobile Application

A Flutter-based customer application connected to the main Wassiili system built with ASP.NET Core. The app allows Syrian customers to shop from platforms such as SHEIN inside the app, add products to an internal cart, send carts for pricing, track pricing requests, manage wallet payments, and receive notifications while keeping the core operational workflow inside the main Wassiili system.

Customer Mobile App

Business Purpose

The application was designed to simplify the customer ordering experience, reduce manual communication, organize pricing requests, and connect the mobile customer journey directly with internal pricing, finance, approval, and operational teams.

Technical Stack

Flutter Dart Riverpod WebView HTTP APIs Flutter Secure Storage ASP.NET Core API JWT Authentication EF Core SQL Server

Security and API Controls

  • Secure token storage on the device.
  • JWT-based mobile authentication with independent API flow.
  • X-App-Build header to identify application build versions.
  • Ability to block outdated application versions from API usage.
  • Rate limiting on /api/v1 routes to reduce abuse and pressure.
  • Payment submissions rejected when receipt image is missing.
  • User validation before showing wallet, requests, or notifications.
  • Production usage based on HTTPS and standard protection policies.

Operational Note

The mobile application does not replace the Wassiili system. It extends it with a customer-focused interface while keeping pricing, finance, approval, management, and operational logic connected to the same database and business workflow.

Wassiili System

A business operations platform built with ASP.NET Core MVC and SQL Server to manage customer orders, product requests, carts, bags, payments, wallets, pricing, shipping stages, employee workflows, and operational tracking for a shopping intermediary business.

Operations Platform

Business Context

The system supports the operational workflow of receiving customer orders from platforms such as SHEIN and Trendyol, pricing them, purchasing them, tracking arrival, grouping products into shipping bags, sorting them, calculating payments, and managing delivery to customers.

Core Modules

  • User and customer management
  • Roles and permissions
  • Pricing requests and product records
  • Carts, bags, and shipment batches
  • Customer wallet and payments
  • Exchange rates and financial tracking
  • Admin dashboards and employee operation pages
  • Search, filtering, Excel import/export, and notifications
Order LifecycleProducts move from customer request to pricing, approval, purchase, arrival, sorting, and delivery.
Carts & ProductsProduct records are connected to pricing requests, carts, and customer ownership.
Bags / ShipmentsProducts are grouped into bags and tracked across shipping and sorting stages.
Wallet & PaymentsCustomer balances, SYP payments, receipts, remaining balances, and histories.
Multi-Currency LogicConceptual handling for SAR, USD, and SYP with exchange rate storage.
Financial ReconciliationFees, discounts, coupons, points, wallet effects, and operational reporting.
Employee DashboardsTables, filters, forms, modals, and internal pages for operational teams.
Security ModelASP.NET Identity, roles, permissions, validation, and secure access control.

Technical Implementation

  • ASP.NET Core MVC and C# for the web application.
  • Entity Framework Core and SQL Server for data access.
  • Repository pattern to keep database operations separated from controllers.
  • Controllers for request handling, validation flow, and coordination.
  • ViewModels for preparing UI-specific data cleanly.
  • ASP.NET Identity for users, roles, and authorization.
  • Program.cs configuration for services, dependency injection, authentication, routing, localization, middleware, and API behavior.
  • Responsive admin pages using tables, filters, forms, modals, and dashboards.

Structured MVC Architecture

The system follows a structured MVC approach where Models represent entities such as customers, products, carts, bags, payments, and pricing requests. Repositories handle database access. Controllers coordinate validation and request flow. Views present employee and admin pages. Program.cs controls services, dependency injection, routing, authentication, middleware, and general application setup.
